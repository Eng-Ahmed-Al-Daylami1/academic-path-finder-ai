# GitHub Upload Guide

## الخطوات:

### 1. إنشاء مستودع على GitHub
- اذهب إلى: https://github.com/new
- الاسم: `academic-path-finder-ai`
- الوصف: `🎓 AI-Powered Career Guidance Expert System using Forward/Backward Chaining, BFS/DFS, and Gemini AI | نظام توجيه مهني ذكي بالذكاء الاصطناعي`
- اختر: Public
- لا تضف README/LICENSE/.gitignore (موجودين)

### 2. رفع المشروع
افتح Terminal/CMD في مجلد المشروع:

```bash
git init
git add .
git commit -m "Initial commit: Academic Path Finder AI v2.0"
git remote add origin https://github.com/YOUR_USERNAME/academic-path-finder-ai.git
git branch -M main
git push -u origin main
```
