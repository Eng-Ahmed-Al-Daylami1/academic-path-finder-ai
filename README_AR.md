## 📋 نظرة عامة

نظام توجيه أكاديمي ذكي يساعد الطلاب والأفراد على اتخاذ قرارات مهنية مستنيرة باستخدام **تقنيات الاستدلال في الأنظمة الخبيرة**. يجمع النظام بين أساليب الذكاء الاصطناعي الكلاسيكية (الاستدلال الأمامي/الخلفي) مع التكامل مع نماذج اللغة الحديثة (Google Gemini).

### 🎯 المميزات الرئيسية

- **🔄 الاستدلال الأمامي**: أدخل مهاراتك ← احصل على تخصصات مرتبة مع نسب الثقة
- **🔙 الاستدلال الخلفي**: أدخل المهنة المطلوبة ← احصل على خارطة طريق كاملة، المهارات المطلوبة، المدة، والراتب
- **📊 التحليل الاستدلالي**: تقييم الصعوبة (0-100) مع أشرطة تقدم مرئية لكل مسار مهني
- **🔍 خوارزميات BFS و DFS**: البحث في الرسوم البيانية عبر خرائط التعلم
- **🧠 التعلم التكيفي**: النظام يتعلم من سلوك المستخدم ويعدل التوصيات
- **🤖 تكامل Gemini AI**: أسئلة وأجوبة بلغة طبيعية للاستفسارات الحرة
- **🌐 دعم ثنائي اللغة**: يقبل مدخلات المهارات بالعربية والإنجليزية عبر تطبيع المرادفات

## 🧠 تقنيات الذكاء الاصطناعي المستخدمة

### 1. الاستدلال الأمامي (Data-Driven Reasoning)
```
مهارات المستخدم: [برمجة، رياضيات]
         ↓
النظام يفحص جميع التخصصات
         ↓
يحسب التقاطع: {برمجة، رياضيات} ∩ {برمجة، رياضيات، بيانات، إحصاء، تعلم آلي}
         ↓
النتيجة: 2/5 = 40% ثقة
         ↓
يرتب جميع التخصصات حسب نسبة الثقة
```

**الكود المسؤول**:
```python
matches = set(user_skills) & set(data["skills"])
confidence = round((len(matches) / len(data["skills"])) * 100, 1)
results.sort(key=lambda x: x[1], reverse=True)
```

### 2. الاستدلال الخلفي (Goal-Driven Reasoning)
```
هدف المستخدم: "خبير ذكاء اصطناعي"
         ↓
النظام يبحث في قاعدة المعرفة
         ↓
يجد: "خبير ذكاء اصطناعي"
         ↓
يستخرج: المهارات + خارطة الطريق + المدة + الراتب
         ↓
يعرض مسار التعلم الكامل
```

### 3. خوارزميات البحث في الرسوم البيانية

**BFS (البحث بالعرض أولاً)**:
- يستخدم Queue (طابور - FIFO)
- يضمن أقصر مسار
- استكشاف مستوى بمستوى

**DFS (البحث بالعمق أولاً)**:
- يستخدم Stack (مكدس - LIFO)
- يجد أول مسار متاح
- استكشاف عميق أولاً

**مثال عملي**:
```
الهدف: الوصول إلى "الشبكات العصبية"

BFS: أساسيات بايثون ← الجبر الخطي ← تعلم الآلة ← الشبكات العصبية
DFS: أساسيات بايثون ← مكتبات بايثون ← تعلم الآلة ← الشبكات العصبية
```

### 4. التعلم التكيفي
```python
# النظام يتذكر اهتمامات المستخدم
career_counts["خبير ذكاء اصطناعي"] += 1

# يعزز الثقة في التوصيات المستقبلية
boost = min(counts.get(career, 0) * 5, 20)  # حد أقصى 20%
confidence = min(confidence + boost, 100)
```

**كيف يعمل**:
- المرة الأولى: ذكاء اصطناعي = 60%
- بعد 3 بحثات: ذكاء اصطناعي = 75% ⬆️ (النظام تعلم اهتمامك)

### 5. التحليل الاستدلالي (Heuristic Analysis)
- تقييم الصعوبة بناءً على معرفة الخبراء
- تصنيف بناءً على عتبات محددة (85/70/55)
- ملاحظات مرئية مع أشرطة التقدم

### 6. تكامل LLM (Gemini AI)
- **Constrained Prompting** للاستجابات الخاصة بالمجال
- آلية احتياطية للاستعلامات غير المطابقة
- فهم اللغة الطبيعية
