# Changelog | سجل التغييرات

All notable changes to this project will be documented in this file.

## [2.0.0] - 2024-2025

### Added | إضافات
- 🤖 **Gemini AI Integration**: Natural language Q&A support
- 🧠 **Adaptive Learning**: System learns from user behavior
- 🔍 **BFS & DFS Search**: Graph-based pathfinding through roadmaps
- 🎨 **Modern GUI**: CustomTkinter dark theme interface
- 🌐 **Bilingual Support**: Arabic and English skill inputs
- 📊 **Heuristic Analysis**: Difficulty scoring with visual bars
- 💾 **User Memory**: Persistent storage of user interests
- 🔄 **Forward Chaining**: Skill-based career matching
- 🔙 **Backward Chaining**: Goal-driven roadmap generation

### Features | المميزات
- 8 tech specializations in knowledge base
- Real-time confidence scoring
- Interactive chat interface
- 4-tab navigation (Chat, Careers, Skills, Help)
- Skill normalization with 50+ aliases
- RTL Arabic interface
- Threading for smooth UI experience
- Visual progress indicators

### Technical | تقني
- Python 3.8+ compatibility
- MVC architecture pattern
- Expert system implementation
- Set intersection for skill matching
- Queue-based BFS algorithm
- Stack-based DFS algorithm
- JSON-based user memory
- Environment variable configuration
